Episode 03 · trying random tech things until i fall in love with tech

---

## What is this?

A Pac-Man game built in Java by following a tutorial — 
as part of my public tech learning journey on Instagram.

Built solo. No AI. Just me, Java, and a lot of bracket errors.

---

## What I learned

- How game loops work in Java
- How to create and render a game frame
- How to add game elements step by step — 
  walls, characters, ghosts
- How to read and fix errors independently
- That yellow lines in VSCode are not always the end of the world

---

## How to run it

1. Make sure Java is installed on your machine
2. Clone this repository
3. Open in VS Code or any Java IDE
4. Run the main file
5. Pac-Man should appear — if not, check your Java setup first
